## ⚙️ Как переключить ветку локально

Если вы клонировали репозиторий себе на ПК, переключиться на нужную лабораторную работу можно через терминал:

```bash
# Обновить список веток с удаленного репозитория
git fetch

# Переключиться на нужную лабораторную (например, первую)
git checkout feature1lab
```
